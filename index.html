How to publish your questions
  1. Export the group’s JSON file.
  2. Put it in your website’s data/ folder, replacing the matching file. Import the existing file first if you want to keep its questions.
  3. For a new group, add its name and file path to data/groups.json.
  4. Upload separate image files to images/. Embedded uploads need no separate image file.
  5. Commit the changes in GitHub. They appear when GitHub Pages finishes deploying.
