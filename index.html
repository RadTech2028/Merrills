Back up or restore progress

Progress saves automatically in this browser. It does not sync to another device. Export a backup before clearing browser data or changing devices. Anyone using this same browser profile shares this history.

Restoring merges histories and keeps the newer record for each card. Progress backups contain marks and statistics. Back up personal questions separately in My questions.

Add a category, subcategory or focus

Custom categories, subcategories and focuses are personal. Question backups include them. The program catalog can also be expanded through its data files.

Publish questions for everyone
  1. Import the existing category JSON first if you want to keep its published questions.
  2. Export the category, then upload the JSON into your website’s data folder.
  3. Register categories in groups.json, subcategories and their projections/topics in projections.json, and focuses in focuses.json.
  4. Commit changes in GitHub to publish.

Publishing replaces the entire category file. A personal backup can instead be imported into another browser without changing the website.
