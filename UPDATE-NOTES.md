# Guides update

Upload these four files to the top level of your existing **Merrills** repository, replacing the matching files:

- index.html
- preferences.js
- guides.js
- guides.css

Keep your existing data and image folders. This update builds on the previous Guides update. No Google configuration or Apps Script changes are needed.

**Read** shows the guide normally. Tap any section heading to close or reopen it. The layout stays saved across projections and visits.

**Review** uses the same page with answers hidden. Tap **Show answer** for one section, or use **Show all answers**. Changing projections hides the answers again. Revealing text does not earn XP or mark anything learned.

**Quick test** keeps the question-by-question approach. Select its criteria and scope in **Guide settings**. Missed items return to the pile. Correct self-assessments use the existing progress, XP and badge system.

The corner **Guide settings** control also lets you switch key distinctions off, expand or collapse all sections, and open the main settings. Hidden key distinctions are excluded from quick tests and the overview.

The receptor cards use **LW** for lengthwise and **CW** for crosswise. Both appear when the source allows both orientations.

Themes, accent colors, text size, spacing and reduced motion apply to the guide interface. Saved count, timer, smart-review and shuffle settings apply to quick tests. Practice mode, question-source and image-question filters remain specific to the question bank.

Guide layout choices are saved inside the existing preferences object and included in cloud sync. Your existing projection IDs and progress records are unchanged.

Functional checks covered revealing/hiding, saved collapses, settings, repeat handling, timer expiry, badges and backup compatibility. Physical iPhone layout testing is still needed.
